# ATHENA Interactive MVP

这是 ATHENA / HAST-DT 的可运行交互原型，用来验证：

- 身体状态输入是否容易理解；
- 红旗症状是否会阻止不安全的测试和干预；
- 60 分钟连续坐姿触发后，用户能否完成一次低负担决策；
- 接受、延后、版本和安全门控是否都能写入研究日志。

## 运行

在当前目录启动静态服务：

```bash
python3 -m http.server 8765
```

打开 `http://127.0.0.1:8765/`。

## 演示路径

1. 在“今日状态”点击“模拟 +20 分钟”，累计到 60 分钟；
2. 在“干预任务”选择 B2-WALK、B2-STS、B2-MOB 或 DEFER20；
3. 在“身体检查”勾选“胸部不适”等红旗症状，观察安全层如何暂停主动干预；
4. 在“研究记录”导出本次演示 JSON。

## 重要边界

这是研究和产品交互原型，不是医疗器械、诊断工具或运动处方系统。原型中的心率、RPE、疲劳、疼痛和测试阈值均为演示字段；正式研究前必须由运动医学/康复专业人员确定筛查标准、设备质量要求、急救与人工升级 SOP，并完成伦理审查。
